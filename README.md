# ExifCraft · Professional EXIF Editor

**v2.1.1** — 一个干净、现代的图片元数据（EXIF）读写工具，面向**批量处理**设计。

ExifCraft 是纯 Python 桌面应用，基于 Tkinter，无需浏览器、无需大型框架。它可以给一整个文件夹的照片批量写入 GPS 坐标、相机信息、曝光参数和拍摄时间，并把结果导出为 CSV。

处理时遵循两条「只」：**只处理你勾选的文件，只写入你勾选的字段**。

![preview](preview.png)

## ✨ 功能特性

- **🔁 批量处理** — 选文件夹即可批量写入；后台线程执行，界面不卡，带进度条与逐行状态反馈
- **🎯 字段级三态** — 每个字段独立控制：勾上=写入、点 ✕=清除、不勾=保持原值（批量改 GPS 时拍摄时间一个字节都不会变）
- **📋 模板 EXIF 导入** — 从任意一张照片读出元数据填表，再批量套用到勾选的文件上
- **↩ 一键回滚** — 副本模式删除生成的副本，覆盖模式从备份还原原文件；一次撤销本次会话的全部操作
- **🖼 缩略图预览** — 选中即预览，显示文件名、真实分辨率与体积，自动纠正拍摄方向（EXIF Orientation）
- **🎬 实况照片安全** — Live Photo 按字节级写入，视频、XMP、MPF 第二图像逐字节保留，不会被打成静态图
- **📍 地图选点**（可选）— 集成 `tkintermapview`，点击地图拾取坐标，确认后才写入表单；瓦片带本地磁盘缓存，第二次打开同一区域秒开
- **📅 日期选择器**（可选）— 集成 `tkcalendar`，日历控件选拍摄日期
- **📊 CSV 导出** — 把当前已勾选文件的 EXIF 摘要导出成表格
- **🛡 安全写回** — 默认输出 `*_exif` 副本，原图不动；也可勾选原地覆盖（自动备份）
- **🎨 现代 UI** — 浅色卡片式三列布局，跨平台 ttk 主题，Windows 下启用 HiDPI
- **✅ 输入校验** — 经纬度范围、数值格式、日期格式前端校验，错误提示清晰

## 🚀 快速开始

### 环境要求

- Python 3.10+

### 安装依赖

```bash
pip install -r requirements.txt
```

> `PyMuPDF` 为可选依赖，仅用于从 `app_icon.svg` 重新生成图标，运行应用不需要它。

### 运行

```bash
python ExifCraft.pyw
```

> `.pyw` 扩展名表示无控制台窗口运行，直接双击即可启动。

## 🔁 批量处理

一次操作搞定几百张照片，而且精确控制改动范围。

### 1. 勾选要处理的文件

左列是文件表格（**复选框 / 文件名 / 状态**），**写入只作用于已勾选的文件**：

| 操作 | 效果 |
|---|---|
| 单击一行 | 切换该行勾选，同时预览该图 |
| 按住左键上下拖拽 | 扫过一片连续行，统一勾选或取消（拖到上下边缘自动滚动） |
| 点击「文件」列头 | 排序（升序 → 降序 → 恢复导入顺序），勾选状态始终跟着文件走 |
| 列表下方 全选 / 全不选 | 批量切换，底部实时显示 `已勾选 N` |

列表内容全部来自内存，**不会 stat、打开或解析任何文件**——在远程硬盘或 NAS 上浏览上千张图片也是瞬间完成。

### 2. 勾选要写入的字段（三态）

右侧每个字段左侧是勾选框、右侧是 ✕ 按钮：

| 状态 | 含义 |
|---|---|
| ☑ 有值 | 写入这个值 |
| ☑ + ✕（框变空） | 删除该字段 |
| ☐ 未勾选 | 保持原文件里的值，**完全不动** |

> 典型用法：给整个文件夹统一改拍摄地点，但保留各自原本的拍摄时间 —— 只勾 Longitude / Latitude，其余全部取消勾选，然后点 Write EXIF。时间字段一个字节都不会变。
>
> 日期行整行由一个勾选框控制（`tkcalendar` 的 DateEntry 没有「空」状态，清空会跳回今天），所以不勾 = 不修改日期。
>
> GPS 卡片底部的 **✕ 清除 GPS 信息** 可整块删除经纬度与海拔，常用于发图前抹掉定位隐私。

### 3. 快捷模块与模板导入

- **快捷选择**（中间列顶部）：**设备**（制造商/型号）、**曝光**（焦距/光圈/ISO）、**时间**（拍摄日期）、**GPS**（经纬度/海拔）。点某个 = 只勾选该模块，其余字段不参与写入；该模块已全勾时再点 = 整组取消。**全部** = 全选 / 全不选
- **模板 EXIF 导入**（File / Folder 按钮旁）：选任意一张照片（**不必在当前列表里**），把它的 EXIF 读进表单，再批量写到勾选的文件上。适合「拿一张参数正确的照片，给一批照片统一署名」。导入**只填值、不自动勾选字段**

### 4. 写入与实时反馈

点 **Write EXIF** 开始：

- 后台线程处理，主界面可继续操作，进度条显示 `N / total`
- 状态列**随进度实时更新**：批量开始 → 全部「写入中」→ 每完成一个立刻变「已写入」，失败变「失败」
- 日志逐条记录；遇到 Live Photo 会额外标注 `· Live Photo（视频已保留）`
- 全批结束后与操作日志对账一次，保证列表状态准确
- 默认在输出目录生成 `<原文件名>_exif.<扩展名>` 副本；勾选 *Overwrite originals in-place* 则覆盖原图

**实测开销**：状态列逐行更新约 4.6 µs/行，1000 个文件的总开销约 5.6 ms，相对实际 I/O 可以忽略。

### 5. 批量撤销

**↩ Rollback** 一次撤销本次会话的全部操作：

| 模式 | 行为 |
|---|---|
| 副本模式（默认） | 删除本次生成的 `*_exif` 副本，**原文件一个字节没动** |
| 覆盖模式 | 从隐藏备份还原原文件 |

写入完成后按钮才可用；撤销后自动变灰。

### 6. 批量导出

**Read folder EXIF → CSV**：把当前**已勾选**文件的 EXIF 摘要导出为 CSV 表格。

## 🛡 安全与备份

- 勾选 *Overwrite originals in-place* 时，程序在**原图所在目录**生成隐藏备份 `._ExifCraft_bak_<会话>_<文件名>.exifbak`
  - 采用重命名（rename）而非复制，即使在远程 HDD / NAS 上也几乎瞬间完成
  - 备份带隐藏属性且扩展名非图片，不会被相册、刮削器等工具误扫
- 写入过程中或完成后，随时点 **↩ Rollback** 撤销
- **关闭程序即保存**：不再弹确认框，也不撤销任何已完成的写入。要撤销就自己点 Rollback
- 退出时自动清理备份文件，不会在磁盘上留下占用空间的垃圾
- 若上次异常退出（强杀、断电），下次启动会自动检测并还原中断的写入；残留孤儿备份会提示是否清理

## 🎬 实况照片（Live Photo）支持

程序按**文件字节**判断类型，不依赖扩展名（`.jpg` 既可能是普通照片，也可能是 Live Photo）：

| 类型 | 判定依据 | 写入方式 |
|---|---|---|
| 普通 JPG | 仅 JPEG 结构 | 只改 EXIF 段，**像素数据不重新编码** |
| Live Photo | EOI 后有视频 / XMP 声明 `MotionPhoto` / 有 MPF 段 | 同上，且**视频、XMP、MPF 第二图像逐字节保留** |

批量写入时每张都会自动校验，任一失败即报错而不会写出坏文件：

- EOI 之后的视频区与源文件**逐字节相同**
- XMP 声明的视频长度仍精确落在 `ftyp` 上
- MPF 第二图像的偏移仍指向合法的 JPEG

实测：一张 7.1 MB 的实况照片写入后文件大小不变，视频区逐字节相同（旧版本走 Pillow 重新保存时会掉到 4.6 MB，视频彻底丢失）。

## 📖 界面布局

窗口分三列，**所有分隔条都可以拖拽**（鼠标移到缝隙上会变成调整光标）：

| 列 | 内容 |
|---|---|
| 左 | 文件列表：路径、表格、全选、覆盖选项 |
| 中 | 快捷选择 + EXIF 表单（可滚动）→ 日志（默认 4 行，可拖高） |
| 右 | 预览：图片按可用空间自动缩放，下方分隔条可调整图片区高度 |

预览框下方的圆点手柄可上下拖拽放大缩小（松手后按新尺寸重新解码）。

路径框采用**右对齐、尾部优先**：长路径自动滚到末尾，优先显示文件名；想看前面的盘符和上级目录，拖动输入框下方出现的细滚动条即可（路径不长时自动隐藏）。

### 地图选点（可选）

安装 `tkintermapview` 后可用：

- 点地图**只预览坐标**，点右下角「确认」才写入表单并关闭；直接关窗口则保持原值，误点无害
- 底部显示 `本地缓存 x MB · n 张瓦片`，旁边是「清理缓存」。瓦片存在程序目录下的 `map_tiles.db`，默认上限 100 MB，满了自动淘汰最旧的
- 请求带 6 秒超时，网络不通时快速返回空白瓦片而不是一直转圈
